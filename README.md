# ⚡ React Modern Todo

A beautiful, modern Todo app built with **React + Vite + Tailwind CSS**.

## Features
- ✅ Add, edit, delete, complete tasks
- 🔄 Drag & drop reordering
- 🌙 Dark / Light mode toggle
- 🔍 Search & filter
- 💾 Auto-saves to localStorage
- 📈 Task counter & progress

## Quick Start

```bash
npm install
npm run dev
```

Then open http://localhost:5173

## Tech Stack
- React 18 + Vite
- Tailwind CSS 3.4
- Lucide-react icons
- Framer Motion (smooth animations)
